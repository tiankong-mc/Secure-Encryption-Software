# -
可以上传文件进行加密，目前支持在线预览的文件较少，后期会加更多文件的。验证方式多样，并且保证你的加密文件安全
功能说明
首次启动：引导设置安全问题和至少一种验证方式（密码、TOTP、邮箱等）。

登录：选择任意已启用的验证方式通过后进入主界面。

上传加密：选择文件，可选用户存储位置，可标记高级文件并指定二次验证组合。

查看文件：双击列表文件，普通文件直接预览（文本/图片），高级文件弹出二次验证。

错误5次：触发紧急备份邮件发送，发送至预设邮箱，并销毁原始文件。

设置：可在主界面设置中开关自动备份和邮件发送。

紧急恢复代码选项，可以在设置中生成恢复代码，每个恢复代码仅可使用一次

文件标签/文件夹分类：
允许用户创建虚拟文件夹（标签），将加密文件拖拽归类，支持按标签筛选。

支持拖拽上传，允许拖拽文件到窗口直接上传。

导出完整保险库（一键迁移）：
新功能：在设置中增加“导出保险库”向导，将 加密文件存储区 + 配置文件 + 索引 自动打包成一个 SecureVault_Backup.vaultbk 文件（可加密），并在新电脑上通过“导入保险库”一键恢复。

暗黑主题：在设置中增加深色模式切换，护眼且专业。

新增：
1.在设置中增加了移动端网页版，移动端可以直接扫描二维码进入（但需要再同一个局域网下）
2.增加了检查更新的功能，可以直接在软件中检查更新并更新，可以不用每次都到github上下载最新版了。


如果运行python源文件请安装python依赖
方法如下：
1.在根目录下右键，打开终端
2.在终端内输入pip install -r requirements.txt安装依赖
